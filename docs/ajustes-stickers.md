# Ajustes y stickers

Tras recortar al sujeto se muestran los ajustes y el efecto **Sticker**. Cada cambio (al soltar el deslizador o al elegir un efecto) se aplica sobre el recorte ya calculado, sin volver a quitar el fondo.

## Tono

Los deslizadores parten de 100 % (sin cambio), salvo la nitidez, que por defecto aplica un toque (115 %).

| Control | Qué hace | Rango |
| --- | --- | --- |
| Brillo | Aclara u oscurece el sujeto | 50 % – 150 % |
| Contraste | Marca más o menos la diferencia de luces |
| Saturación | Intensidad del color |
| Nitidez | Un poco de enfoque en bordes y detalle | 100 % – 200 % |

Solo se modifican los píxeles del sujeto; la transparencia no se altera.

## Efectos sticker

| Opción | Resultado |
| --- | --- |
| Sin efecto | El recorte tal cual |
| Contorno (sticker) | Borde alrededor del sujeto. El color se elige en **Color del contorno** (hex) |
| Sombra | Sombra suave desplazada, útil en miniaturas y pegatinas |

El contorno y la sombra se generan a partir de la máscara, así que siguen el pelo y los huecos del recorte.
