# Formatos y tamaños

La tarjeta **Formato y tamaño** aparece después del recorte. Al cambiar formato o tamaño se vuelve a exportar el archivo actual.

## Formatos

| Formato | Uso |
| --- | --- |
| PNG (transparencia) | Recortes, stickers y edición posterior |
| JPEG (con fondo) | Fotos opacas, más ligeras. Sin canal alfa |
| WebP | Buena compresión; puede conservar transparencia |
| ICO | Iconos; se genera un `.ico` de 256×256 (con tamaños 16, 32, 48 y 256) |

El nombre de salida termina en `_sinfondo` más la extensión: `.png`, `.jpg`, `.webp` o `.ico`.

## Tamaños

El sujeto se encaja centrado en el recuadro (sin deformarlo). El espacio libre queda transparente o con el [fondo de salida](fondos-salida.md).

| Opción | Píxeles | Uso típico |
| --- | --- | --- |
| Tamaño original | El del recorte | Máxima calidad |
| Avatar 512×512 | 512 × 512 | Perfiles y avatares |
| Miniatura 256×256 | 256 × 256 | Miniaturas y listados |
| Instagram 1080×1080 | 1080 × 1080 | Publicación cuadrada |
| Story 1080×1920 | 1080 × 1920 | Historias verticales |
| Facebook 1200×630 | 1200 × 630 | Enlaces y portadas |

La última elección de formato y tamaño se guarda para la siguiente sesión.
