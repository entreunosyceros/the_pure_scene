# Atajos e interfaz

## Atajos de teclado

En la ventana principal (no en editores a pantalla completa):

| Atajo | Acción |
| --- | --- |
| Ctrl+O | Abrir una o varias imágenes |
| Ctrl+V | Pegar rutas de archivos o carpetas |
| Enter | Procesar (hace falta origen y destino) |
| Esc | Cancelar el lote en curso |

## Menú de la barra superior

| Entrada | Función |
| --- | --- |
| Cómo funciona | Resumen breve del flujo |
| Buscador de Imágenes | [Buscar fotos gratuitas](buscador.md) |
| Añadir Texto a Imagen | [Editor de texto](anadir-texto.md) |
| Acerca de | Logo, descripción y enlace al repositorio |
| Cerrar aplicación | Pide confirmación y cierra ventana, proceso y bandeja |

## Bandeja del sistema

Al iniciar aparece un icono (`assets/tray-icon.png`). Desde ahí puedes salir. Cerrar la ventana también pide confirmación para no perder un procesado a medias.

## Acerca de

Muestra el nombre **The Pure Scene**, `assets/logo.jpeg` y el enlace al repositorio [github.com/entreunosyceros/the_pure_scene](https://github.com/entreunosyceros/the_pure_scene).
