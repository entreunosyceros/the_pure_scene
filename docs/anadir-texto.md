# Añadir texto

Menú → **Añadir Texto a Imagen**. Abre una pantalla a tamaño maximizado, independiente del recorte de fondo.

Si no cargas nada, la vista previa usa `assets/default-image.png`.

## Cómo usarlo

1. **Cargar imagen** (PNG, JPEG o WebP).
2. Escribe el texto, elige fuente, tamaño y color hexadecimal.
3. Pulsa sobre la imagen para colocar el texto, o **Añadir texto** para ponerlo cerca de la esquina.
4. Con las flechas (Arriba, Abajo, Izq., Der.) mueves el texto seleccionado.
5. **Actualizar texto** aplica los cambios del formulario al texto activo.
6. **Eliminar texto** quita esa capa.
7. **Guardar imagen** exporta un PNG con el texto pintado.

## Fuentes incluidas

Están en `assets/fonts/`:

- Arial
- Times New Roman
- Courier New
- Comic Sans
